Expand description

A trait for types that can be constructed from a name string.

This trait enables NamedMap<T> to support dual-format input: when deserializing from a simple list like ["iface1", "iface2"], each name is turned into a meaningful default value via from_name.

§Example

use flexicon::adaptive::FromName;

#[derive(Clone)]
struct Capability {
    name: String,
    version: String,
}

impl FromName for Capability {
    fn from_name(name: &str) -> Self {
        Self {
            name: name.to_string(),
            version: "latest".to_string(),
        }
    }
}

Required Methods§

fn from_name(name: &str) -> Self

Construct a value from its name.

This method should never fail. Even if the name is malformed, return a sensible fallback (e.g., with version: "unknown"). Validation, if needed, should happen at a higher layer.

Dyn Compatibility§

This trait is not dyn compatible.

In older versions of Rust, dyn compatibility was called "object safety", so this trait is not object safe.
