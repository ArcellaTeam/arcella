Expand description

Extracts the base name from a file path by stripping a required extension.

Examples:

  • "/x/app.wasm" → "app" (if ext = "wasm")
  • "web.deployment.toml" → "web" (if ext = "deployment.toml")

§Errors

  • If file has no name
  • If extension does not match exactly
